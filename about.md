# Geometry Dash Space World

Geometry Dash Space World is a Geometry Dash mod created by R3ALCYB3R.

Space World features 4 stages containing a total of 14 levels:

* Stage 1: 3 levels
* Stage 2: 4 levels
* Stage 3: 4 levels
* Stage 4: 3 levels

## Compatibility

* Geometry Dash 2.2081
* Windows
* Android
* macOS
* iOS
