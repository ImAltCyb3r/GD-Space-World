## Geometry Dash Space World

Geometry Dash Space World is a Geometry Dash mod created by R3ALCYB3R.

Space World is built around a four-stage progression system containing 14 levels in total.

Stages

Stage	Levels
Stage 1	3
Stage 2	4
Stage 3	4
Stage 4	3
Total	14

Compatibility

Geometry Dash Space World currently targets:

* Geometry Dash 2.2081
* Windows
* Android
* macOS
* iOS

Dependencies

Space World uses:

* Geode
* geode.node-ids >= v1.23.3


Developer

R3ALCYB3R

Status

Geometry Dash Space World is currently in development.

More information, features, levels, and content will be added as development continues.
